## A-1. 中核の単体試験（`app/test/engine.test.js`、23件）

条件：Node.js v22.22.0／Linux（クラウドのコンテナ）／時計を差し替えたテスト（期限・時間上限を即時に再現）

| 確認したこと | 試験名 |
|---|---|
| 全員に聞く：発言順どおり、前の回答を一度だけ渡す | ask all: sequential order… |
| AIだけで続ける：2巡6発言で自動停止。2巡目は1巡目を受け取る。自分の発言は渡さない | auto run: 2 rounds = 6 utterances… |
| 会議ルール・議題・役割は初回と変更時だけ渡す | charter, premise and role are sent once… |
| 重複通知・重複投稿で進行が二重に進まない。別本文の再投稿は拒否し、原文は記録に残す | duplicate delivery and duplicate post… |
| 生成中の割込：処理中の回答は旧前提として記録し、転送しない。進行は一時停止 | interrupt during generation… |
| 一時停止：処理中の回答は有効。新しい依頼は出さない | pause keeps the in-flight answer valid… |
| 停止：処理中の依頼を取消し、遅れた回答は旧前提として記録 | stop cancels in-flight request… |
| 期限切れ：一時停止し、自動再依頼しない。スキップで先へ進む | timeout: request expires… |
| 利用上限の報告で一時停止し、エラー表示 | usage limit report… |
| 権限：他人の依頼へ投稿できない。読取権限なしは読めない。書込権限を外すと依頼を取消 | permissions… |
| 存在しない依頼への投稿を拒否して記録 | posting to a request of an unknown meeting… |
| 独立ラウンド：同じラウンドの他AIの回答は見えない（`get_messages` でも） | independent round… |
| 独立ラウンド＋割込：議長の発言は見え、他AIの回答は隠れ、次のラウンドで一度だけ届く | independent round + interrupt… |
| 再起動後の復元：状態が同じで、重複検出も働き、進行を続けられる | restore after restart… |
| 書込み途中で落ちた最終行を無視して復元 | restore tolerates a torn last line |

## A-2. 実際の通信での結合試験（`app/test/integration.test.js`、9件・模擬参加者）

実際の HTTP と MCP（SDK v2 のクライアント）で、模擬参加者をつないで試験しました。
- 模擬 Claude：2025年版プロトコルで接続し、タスク内で待機する
- 模擬 ChatGPT：2026-07-28 版プロトコルで接続し、MCP Events の Webhook で起こされる（署名を検証）
- 模擬 Gemini：参加者ページのフォームで投稿する

| 確認したこと | 結果 |
|---|---|
| 3経路の混在で 6発言 → 9発言。人の操作なし。2巡目以降の回答はすべて直前のAIを引用。依頼IDの重複なし | 成功 |
| 接続試験：パネル再起動・MCP Events 再起動・参加者ページを正しく分類し、3つとも「成立（自動）」 | 成功 |
| 生成中の停止：遅れた回答は `stale`・未転送。停止後に新しい依頼は出ない | 成功 |
| 応答が失われた場合の再投稿は「重複」。別本文は `already_answered` | 成功 |
| 待機中に接続が切れても、その依頼を「受信済み」にしない | 成功 |
| 不明なトークンは 404。他人の依頼への投稿は forbidden。議長APIはトークンなしで 403。AI向けツールに設定変更の機能がない | 成功 |
| MCP Events：http の送信先や短い秘密鍵を拒否。購読IDは同じ条件なら同じ。同じイベントが重複して処理されても投稿は1件。1依頼につき起こす通知は1回。購読解除 | 成功 |
| 再起動：議事録・未回答の依頼・購読が残り、再起動後も Events で回答が届く | 成功 |
| 旧版（2025）と新版（2026-07-28）のどちらの応答も `application/json`（SSE非対応のトンネル対策）。`server/discover` で `events` を広告 | 成功 |

実行：`cd app && npm test` → `# pass 32 / # fail 0`（3回連続で同じ結果）

## A-3. 画面の操作確認（Playwright・模擬参加者）

`npm run demo:mock` で模擬参加者つきのサーバーを起動し、ブラウザ（Chromium）で議長画面を操作しました。
- 「全員に聞く」→ 3社分の回答が時系列に並ぶ
- 「AIだけで続ける」6回 → 途中で「発言のみ／割込」→「一時停止」表示 →「再開」→「回数上限 6 回に到達」で完了
- 接続試験（ChatGPT・MCP Events・待機0秒）→ 結果表に「成立」と「MCP Events → get_my_turn」が表示される
- 連結試験「2巡・6発言」→ 完了。「3巡・9発言」を開始し、処理中に「停止」→ 遅れた回答が「旧前提・未転送」として1件表示される
- ページを再読み込みしても、発言13件が同じく表示される（復元）
- 幅390pxで横方向のはみ出しなし。画面上のJSエラーなし
